# \# 电商零售用户行为与价值分析

# 

# \## 项目背景

# 基于UCI Online Retail公开数据集（英国在线零售商真实订单数据），对销售趋势、用户价值、商品结构进行多维度分析，为精细化运营和精准营销提供数据支撑。

# 

# \## 数据说明

# \- 数据来源：UCI Machine Learning Repository - Online Retail

# \- 原始数据量：54万+条订单记录

# \- 清洗后数据量：397,884条，覆盖4,338位用户、3,665件商品

# \- 时间范围：2010年12月 - 2011年12月

# \- 字段：发票号、商品代码、商品描述、购买数量、单价、购买时间、客户ID、国家

# 

# \## 技术栈

# \- \*\*数据处理\*\*：Python (Pandas, NumPy)

# \- \*\*数据可视化\*\*：Matplotlib, Seaborn

# \- \*\*分析方法\*\*：RFM用户分层模型、销售趋势分析、复购分析、商品结构分析

# 

# \## 分析框架

# 1\. \*\*数据清洗与预处理\*\*：缺失值处理（删除无CustomerID记录）、取消订单过滤、异常值剔除、特征工程（计算消费金额、提取时间特征）

# 2\. \*\*整体销售趋势分析\*\*：销售额、订单数、客单价的日度趋势

# 3\. \*\*RFM用户分层模型\*\*：基于最近消费(R)、消费频次(F)、消费金额(M)三维度，将用户分为8个价值层级

# 4\. \*\*热销商品分析\*\*：按销售额统计TOP10商品

# 5\. \*\*用户活跃时段分析\*\*：各时段订单数分布，识别消费高峰

# 6\. \*\*复购行为分析\*\*：用户复购率与订单数分布

# 

# \## 核心结论

# 1\. \*\*用户价值高度集中\*\*：重要价值用户仅占30.4%，却贡献了73.0%的销售额，是运营的核心群体，建议优先维护并推出会员专属权益

# 2\. \*\*用户粘性良好\*\*：用户复购率达65.6%，说明产品和服务具有较强的用户吸引力，可进一步通过召回策略激活流失用户

# 3\. \*\*消费高峰明确\*\*：订单高峰时段为12点，建议在该时段加大活动推送力度和客服资源配置

# 4\. \*\*商品结构呈长尾分布\*\*：TOP10商品贡献了主要销售额，爆款效应明显，可围绕爆款做关联推荐提升客单价
